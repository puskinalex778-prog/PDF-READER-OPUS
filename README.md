# PDF Reader Opus

Простая читалка PDF для Android (Kotlin, встроенный `PdfRenderer`, без сторонних библиотек).

- Открытие PDF через выбор файла или «Открыть с помощью…»
- Вертикальная прокрутка страниц, масштаб ＋/－, номер страницы в заголовке

## Сборка
GitHub → вкладка **Actions** → workflow **Build APK** → артефакт `PDF-Reader-Opus-APK`.
